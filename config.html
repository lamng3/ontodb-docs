    Using OntoDB

    Settings

    \set prints the settings and \set knob value changes one. Settings last for the shell process.

    2. Timing

    Settings

    OntoDB> \set
backend mem
pool_size 64
lru_k 2
join nlj
isolation rc
    KnobValuesDefaultEffect today
    backendmem, indexedmemindexed answers not built yet (PLAN 3.4) and is not stored
    pool_sizeframes64Stored for the buffer pool, which is being built
    lru_kpositive integer2Stored for the buffer pool's LRU-K eviction, which is being built
    joinauto, nlj, inlj, hashnljJoin operator. inlj and hash answer not built yet (PLAN 4.2, 4.3) when a query runs
    isolationru, rc, rr, serrcStored for transactions, which are being built

    A setting that is accepted prints ok. An unknown knob or value prints an error and changes nothing.

    Timing

    \timing on prints time: N ms after each statement's result. \timing off stops it.

    Statistics

    OntoDB> \stats
page reads: 0
page writes: 0
buffer hits: 0
buffer misses: 0
log flushes: 0

    log flushes counts physical log writes in a persistent database; one flush can carry many commits. The page and buffer counters stay at zero until the buffer pool exists.
