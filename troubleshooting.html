    Messages and troubleshooting

    Every message names its cause. This page lists them by where they appear.

    On this page
    1. In the shell
    2. When opening a directory
    3. Questions

    In the shell

    MessageMeaningWhat to do
    not built yet (PLAN x.y)The command or operator belongs to a feature still being builtSee Roadmap
    error: OPTIONAL is not supported at line 1, column 30The statement uses SPARQL outside the supported subsetSee SPARQL reference
    error: ... at line L, column CA parse or bind errorFix the statement at that position
    error: usage: \load <file>A command is missing an argumentRun \help
    error: unknown command (try \help)A backslash line that is not a commandRun \help
    error: nothing on disk to verify; ...\verify in an in-memory databaseStart the shell with a directory
    error: ...Any other failure. The statement changed nothingRead the message

    When opening a directory

    MessageMeaningWhat to do
    opened dir: ... N uncommitted droppedN transactions had no commit record, usually from a crashNothing; this is recovery working
    warning: wal stopped: ... at byte B; discarded D bytesThe log had a torn or damaged record. Everything before it was keptRun \verify. If damage was not expected, check the disk
    error: wal: ... not opening in absolute-consistency mode--strict found a damaged log recordCopy the directory, then open without --strict to recover the valid part
    error: snapshot: checksum mismatch (or a bad header or count)The snapshot file was changed or damagedRestore it from a copy. A damaged snapshot cannot be recovered automatically
    error: wal: lsn N gives term T a different spellingThe log disagrees with the snapshot about a dictionary idThe files come from different databases, or one was edited

    Questions

    A query for a class does not return instances of its subclasses. OntoDB does not reason; subClassOf is data. See No reasoning.

    A load is slow on a large file. The in-memory store is not indexed. See Loading data.

    The log keeps growing. Run \checkpoint.
